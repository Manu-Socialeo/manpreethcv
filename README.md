# Manpreeth — Minimal Portfolio & Resume (Website View)

A Scandinavian-inspired, high-impact minimal portfolio and professional resume website designed in the signature **Norden / Hanssen** aesthetic.

Built for **Manpreeth (Founder at Socialeo)** — showcasing bespoke web applications, AI automation systems, client projects, and verified professional certifications.

---

## 🌟 Key Features

- **Signature Desktop "Website View"**:
  - Sculpted landscape bento container (`1200px` max width) with dual 50/50 columns.
  - Cut-out notched corner tabs and interactive badges.
  - Selected work hero slider with interactive `< >` controls and pagination dots.
- **Sculpted Menu Dropdown**:
  - Exactly matching the Norden template header with brand circle, theme switch, `● Available` green pill, top notched bridge tab, `Close` button, and 2-column dark action grid.
- **Verified Certifications Registry**:
  - **Claude Code 101** — Anthropic • Claude Academy (`12d6bf558501fc02760d84eafd6c2645`)

  - **AI Fluency: Framework & Foundations** — Anthropic • Claude Academy (`22709de98df6fc8ddf88a3e61517acc5`)

- **Dual Perspective Switcher**: Toggle between **Hanssen View** and **Manpreeth Founder View**.

## 🚀 Getting Started

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Manu-Socialeo/manpreethcv.git
   cd manpreethcv
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open in your browser:
   ```text
   http://localhost:3000/
   ```
